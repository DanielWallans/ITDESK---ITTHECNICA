# IT DESK — Plataforma de Gestão de Suporte

Plataforma proprietária desenvolvida pela **IT THECNICA** para centralizar atendimentos de TI, conexões remotas via **AnyDesk** e liquidação financeira via **Pix**.

## O que a plataforma faz
- **Central Operacional (`/`)**: Acompanhamento de chamados em fila, tempo de atendimento auditado, alertas sonoros de novas solicitações e controle financeiro.
- **Portal do Cliente (`/atendimento`)**: Abertura rápida de chamados, checklist de diagnóstico, orientações para AnyDesk, chat ao vivo e pagamento via Pix.
